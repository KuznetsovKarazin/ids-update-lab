# Prespecified posthoc percentile-grid diagnostic (revision 035)

Protocol recorded before computing candidate outputs. This is a host-only diagnostic of an alternative quantizer for the already frozen converted B float network. It does not create a new independent test or hardware experiment.

1. Use the frozen `mlp_float_compatible_first_layer.json` network, with the retained A mean and scale. Do not refit its weights. Load the saved B fitting sample (`B_fit.npz`) to determine quantization ranges; labels do not enter range selection.
2. Retain symmetric signed int8 codes [-127,127], layerwise scalar scales, hidden ReLU, per-tensor max-absolute weight scales, int32 bounded accumulation, int64 Q31 products, nearest rounding with ties away from zero, and saturation. Derive input and each layer output scales as max(percentile(abs(float32 tensor), 99.9, method="linear") / 127, 1e-8), stored in float32. Flatten all rows/channels of each tensor for this scalar percentile. Compute layer ranges using the frozen float network, as in the baseline quantizer.
3. Use one percentile only (99.9), with no sweep or result-dependent adjustment. Export two candidate rows: (a) the original B int8 logit cut transferred to the new output grid using the existing transfer rule; (b) recalibration on B calibration normal rows, choosing the most permissive integer cut satisfying empirical row-weighted FPR <= 1%, with score ties kept together. Attack calibration labels are used only for reporting recall.
4. Report the original B int8 model and the frozen max-absolute compatible export with transferred/recalibrated cuts as controls. Verify that our max-absolute mode reproduces all numerical fields of the frozen baseline quantizer; compare its reconstructed fields with the frozen export explicitly.
5. On B calibration rows report normal/attack counts, false/true positives, row-weighted and equal-vector FPR/recall, and changed decisions relative to original B. For equal-vector metrics each distinct raw float32 eight-feature vector has total weight one; conflicting-label rows share that unit weight. Also report the 258 saved check vectors separately as decision agreement only. Their selection is inherited from the frozen manifest, not an independent quality test.
6. Report the target raw vector [0,0,0,0,1,63,0,0]: original and candidate input codes, layer codes, scales, scores, and decisions. Report input/output clipping counts on fitting and calibration samples as diagnostics; these will not select a model.
7. Validate accumulator and int64 product bounds, tie rounding, and percentile implementation. Save source hashes, candidate models, results, and the exact script. No full future test, new hardware result, or unchanged-deployment-ABI claim follows from these host-only calculations.

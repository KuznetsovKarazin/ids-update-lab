# Revision 034: fixed post-hoc host-only export diagnostic

This plan was recorded before computing the new scores. It supplements, and does not replace or retune, the frozen campaign 030 results. The available inputs are frozen B fitting and calibration samples and the 258 common-test hardware check vectors. The complete common-test corpus is unavailable in this workspace.

1. Retain the frozen B int8 network as the reference. Reproduce the already-frozen affine-folded, per-tensor re-quantized export exactly.
2. Construct one host-only alternative: symmetric per-output-channel weight scales, common per-layer activation scale, retaining the frozen fitting-derived max-absolute activation grids, ties-away rounding, bounded int32 accumulation and per-channel Q31 multipliers. Its representation is incompatible with the existing scalar-scale MCU ABI. No retraining or architecture/hyperparameter search.
3. For each export compare the transferred integer decision cut with one recalibrated cut using only the frozen B calibration normals and the original empirical <=1% FPR rule. Report calibration normal FPR and attack recall as resubstitution diagnostics, not independent quality estimates.
4. Evaluate decision agreement with B on the unchanged 258 hardware check vectors (selected originally as the first 258 unique float32 raw vectors in byte order without predictions). Report counts only; this check set is not a representative detection test.
5. Compute conservative pointwise bounds for the converted per-tensor integer network around its exact rational real-arithmetic counterpart. Start from the actual frozen float32 normalized inputs. Bound input rounding/clipping, weight and bias quantization, Q31 scale approximation, requantization rounding and saturation at every layer using exact rational arithmetic. Certify agreement only when the complete bound lies in the B decision's integer region. The guarantee is for the mathematical integer reference on these inputs, not for a raw-input neighborhood or every MCU libm implementation. Validate bounds against the exact integer forward pass. Do not call empirical zero differences a certificate.
6. Report unsuccessful/non-informative outcomes. No new full-test FPR, recall or 7.46-million-row agreement claims will be manufactured from these limited data.

Implementation clarification before any new scores: local NumPy recomputation changes the input grid by 5.96e-8 while all integer weights and biases reproduce exactly. The frozen grids are retained for a controlled quantizer comparison. This change was made after parameter inspection and before evaluating new scores.

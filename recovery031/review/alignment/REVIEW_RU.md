# Независимая проверка восстановления синхронизации FNB58 — серия 030

Вывод: восстановление синхронизации обосновано. Повтор аппаратной серии только из-за ошибки `Marker waveform too noisy` не требуется. Это исправление анализа после просмотра записи, которое следует явно раскрыть; исходный анализ 030 действительно завершился отказом. Отчёт ниже составлен до просмотра интегралов энергии и сравнения способов обновления.

## Причина первоначального отказа

Сигнал нагрузочного маркера не является идеальным прямоугольником. Прошивка после примерно 40 мс вычислений вызывает `vTaskDelay(1)`; при частоте тиков 100 Гц возникают короткие провалы нагрузки. На участке записи 22–27 с доминирует компонента около 20,04 Гц. Исходный поиск корреляции выбирает значения на сетке с шагом 80 мс без предварительного усреднения. Высокочастотная составляющая искажает этот грубый сигнал поиска.

Девятиточечное симметричное усреднение исходной сетки 10 мс перед грубым поиском устраняет основную часть этого эффекта. Значения корреляции четырёх кодов возрастают с 0,73–0,76 до 0,93–0,94. Пороги допуска корреляции и неоднозначности не ослаблены. Это усреднение применяется только для поиска кандидата, а не для расчёта энергии. Уточнение границ использует прежнюю процедуру и исходный сигнал с прежним медианным фильтром.

## Проверенные признаки правильного соответствия

| Проверка | Результат |
|---|---:|
| Найденные границы 16 импульсов | 32 из 32 |
| Максимальное отличие длительности импульса от сообщения MCU | 26,36 мс |
| Максимальный остаток на калибровочных маркерах | 10,53 мс |
| Максимальный остаток на двух маркерах, не участвующих в подгонке часов | 24,88 мс |
| Масштаб времени CFN относительно хоста | 1,00002712456 |
| Сдвиг начала отсчёта CFN | 2,563253757 с |
| Эмпирический запас неопределённости границы | 97,996 мс |

Сдвиг фазы грубой сетки на 10, 20 и 30 мс практически не меняет восстановленные часы. Искусственная плоская запись отклоняется. Две одинаковые копии действительного маркера отклоняются как неоднозначные. Удаление любого из четырёх импульсов исходного маркера также приводит к отказу. Эти проверки выполнены без изменения исходного CFN; модифицированные кривые существуют только как входы диагностических тестов.

## Ограничения

1. Исправление метода поиска сделано после отказа исходного анализатора. Энергетические оценки после исправления нельзя описывать как безусловное выполнение первоначального протокола. Следует сохранить первоначальный отказ и отдельную версию исправленного анализа.
2. Все четыре кодовых маркера находятся около начала и конца серии. Независимые проверочные маркеры подтверждают соответствие этих участков. Линейность хода часов внутри двухчасового интервала остаётся допущением, напрямую промежуточными маркерами не проверенным.
3. Запас 98 мс основан на остатках маркеров, транспортных интервалах и шаге записи. Это эмпирическая оценка, не метрологически аттестованная погрешность всей измерительной системы. Она не описывает точность измерения напряжения или тока.
4. 75,56% соседних значений произведения U×I совпадают. Это не доказывает частоту обновления прибора 25 Гц: одинаковые значения также возникают из-за постоянной нагрузки и округления. Номинальные 100 отсчётов/с нельзя использовать как число независимых наблюдений для статистики.
5. Успешные тесты отсутствующих и повторных маркеров проверяют конкретные сценарии отказа; они не доказывают отсутствие всех ложных соответствий.

Рекомендуется автоматическое исправленное сопоставление с сохранением независимых проверочных маркеров. Ручная установка времени менее проверяема и здесь не нужна. Исходные значения U×I должны оставаться неизменными для всех последующих интегралов, а временной запас должен передаваться в анализ чувствительности границ измерительных окон.

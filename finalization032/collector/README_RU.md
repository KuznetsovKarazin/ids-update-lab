# Полная копия локальных результатов — 032

Сборщик сохраняет результаты, которые пока есть только на вашем ПК: в том числе `runs\ids-completion-030\training\test_vectors.sqlite`, обучающие выборки NPZ и восстановленный анализ `runs\ids-completion-030-energy-031`. Плата и FNB58 не нужны. Никакие эксперименты не запускаются; исходные файлы не изменяются.

После завершения всех программ записи распакуйте комплект в `E:\ids-update-lab` и выполните:

```powershell
Set-Location E:\ids-update-lab
.\.venv030\Scripts\python.exe .\finalization032\collector\collect_local_all032.py --root E:\ids-update-lab --output E:\ids-update-lab\all-local-results-032.zip
```

Ожидаемый результат: `crc_and_member_sha256_verified: true`. Архив включает `COLLECTION_MANIFEST.json` с SHA-256 каждого файла, перечнем исходных статусов опытов и всеми исключениями. Проверка архива подтверждает целостность файлов, а не научные выводы. Неуспешные прогоны тоже сохраняются.

Включаются обычные файлы `runs/` независимо от размера (кроме копий ZIP/7z и других перечисленных исключений), код из `stage*`, `completion*`, `research*`, `review*`, `recovery*`, `preservation*`, `finalization*`, а также стандартные каталоги проекта, `data`, `dataset`, `datasets`, `ton*`, FNB/energy и файлы корня. Виртуальные окружения (включая `.venv030`), кэши и Git-метаданные пропускаются. Нестандартную папку можно добавить через `--include-relative имя_папки`.

Большие исходные CSV/TSV/Parquet/PCAP вне каталогов результатов по умолчанию не встраиваются; для обнаруженных файлов в выбранных папках сохраняются размер и SHA-256. Прежние ZIP не дублируются, в том числе внутри `runs/`; если в них лежат единственные копии результатов, добавьте `--include-existing-archives`.

Для полной локальной резервной копии **с исходными CSV** добавьте `--include-large-datasets`:

```powershell
.\.venv030\Scripts\python.exe .\finalization032\collector\collect_local_all032.py --root E:\ids-update-lab --output E:\ids-update-lab\all-local-with-data-032.zip --include-large-datasets
```

В журнале 030 путь к TON указан как `E:\ids-update-lab\data\ton_full_v1`: эта папка будет выбрана автоматически. Только 23 исходных CSV занимают 3 372 475 448 байт до сжатия. Такой архив предназначен прежде всего для локального хранения; загрузка его в чат не обязательна. Если часть датасетов лежит вне `E:\ids-update-lab`, сохраните их отдельной копией: сборщик намеренно ограничен указанным корнем.

Файлы учётных данных и отдельные приватные ключи исключаются. Единственное исключение — точно совпадающий по SHA-256, намеренно опубликованный учебный ключ `PUBLIC_DEVELOPMENT_ONLY_private.pem` из комплекта 030. Он нужен для воспроизводимости лабораторных подписей и не предназначен для рабочей системы.

Готовый архив и прежний `.partial` не перезаписываются. При конфликте имени выберите `all-local-results-032b.zip`. При изменении исходного файла во время сбора программа остановится, сохранив `.partial` для проверки. Повторите сбор после завершения работающих программ с новым именем.

Записывайте архив на обычный локальный диск NTFS (например, `E:`): после проверки целостности его имя создаётся атомарной жёсткой ссылкой, чтобы исключить перезапись чужого файла. Неподдерживаемая файловая система приведёт к ошибке с сохранением `.partial`.

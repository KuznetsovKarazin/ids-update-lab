# Release 1.0.0 — 26 September 2026

First versioned software and evidence release for the TinyML pipeline-update study.

- Preserves the original measurement series and separates failed runs from later repairs.
- Restores exact hash-bound frozen-kit dependencies, model exports and energy timelines
  omitted by the initial publication-file selection.
- Adds scoped licenses, software-only citation metadata and upstream notices.
- Restores the signed synthetic example fixtures and documents supported offline checks.
- Includes verified-input reconstruction and source-row reference export tools.
- Distributes code and evidence only; the manuscript PDF and complete LaTeX sources remain separate and private.
- Excludes raw source datasets and sampled records; documents acquisition/reconstruction.

This release does not add a new MCU experiment or new detection-performance result.
The final integrity manifest is `MANIFEST.sha256.json`; historical manifests under
`release/provenance/` describe the incoming candidate, not the assembled release.

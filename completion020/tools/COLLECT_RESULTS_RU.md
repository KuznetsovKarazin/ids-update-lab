# Сбор всех локальных журналов

Запускайте, когда экспериментальные скрипты завершились: файлы не должны меняться во время копирования. Плата может оставаться подключённой; коллектор не открывает последовательный порт.

Из PowerShell:

```powershell
Set-Location E:\ids-update-lab
.\.venv\Scripts\python.exe .\completion020\tools\collect_results.py --root E:\ids-update-lab --output E:\ids-update-lab\all-local-results-020.zip --include-relative completion020
```

Имя архива должно быть новым. Если такой файл уже существует, выберите другой номер: коллектор его не перезапишет.

В архив попадут:

- все обычные файлы `runs`, включая неуспешные и незавершённые опыты;
- имеющиеся `research`, `docs`, `stage018`, `stage019`, дополнительно указанный `completion020`;
- исходные CFN в корне проекта и корневые README/протоколы;
- `COLLECTION_MANIFEST.json`: исходные относительные пути, размеры, SHA-256, исключения, статусы из найденных `summary.json`.

Вложенные ZIP, кэши, окружения, закрытые ключи и символические ссылки/junction не копируются. Если CFN лежат в отдельном каталоге, его можно явно добавить ещё одним аргументом, например `--include-relative measurements`.

После упаковки проверяются CRC и SHA-256 всех записанных файлов. `status: complete` относится к успешному сбору архива; он не означает, что все эксперименты успешны или научно проверены. Исходные summaries не исправляются.

Для доступной нам копии старые первичные журналы 001–009 отсутствуют. Если они сохранены в ваших `runs`, этот коллектор добавит их. Готовый ZIP можно прислать для дополнения общего архива анализа.
